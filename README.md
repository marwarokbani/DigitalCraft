# 🎨 DigitalCraft

> Projet web réalisé en HTML, CSS et JavaScript.

## 📋 Description

**DigitalCraft** est un projet web développé dans le cadre d'un travail pratique.

L'objectif du projet est de concevoir une interface web moderne, structurée et interactive en utilisant les technologies fondamentales du développement front-end.

## 🎯 Objectifs

* Concevoir une interface web claire et intuitive.
* Mettre en pratique **HTML5**, **CSS3** et **JavaScript**.
* Organiser correctement les fichiers et les ressources du projet.
* Créer une expérience utilisateur agréable et responsive.
* Développer des fonctionnalités interactives avec JavaScript.

## ✨ Fonctionnalités

* 🖥️ Interface web structurée
* 🎨 Mise en forme avec CSS
* ⚡ Interactions avec JavaScript
* 🖼️ Utilisation d'images et de ressources multimédias
* 📱 Interface adaptable aux différentes tailles d'écran

## 🛠️ Technologies utilisées

| Technologie | Utilisation             |
| ----------- | ----------------------- |
| HTML5       | Structure des pages     |
| CSS3        | Design et mise en forme |
| JavaScript  | Interactivité           |
| Git         | Gestion des versions    |
| GitHub      | Hébergement du projet   |

## 🚀 Installation et utilisation

### 1. Cloner le projet

```bash
git clone https://github.com/marwarokbani/DigitalCraft.git
```

### 2. Accéder au dossier

```bash
cd DigitalCraft
```

### 3. Lancer le projet

Ouvrir le fichier suivant dans un navigateur :

```text
index.html
```

Il est également possible d'utiliser **Visual Studio Code** avec l'extension **Live Server** pour lancer le projet localement.
